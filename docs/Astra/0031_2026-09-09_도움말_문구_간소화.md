# [0031 | 2026-09-09] 도움말 문구 간소화

창작자님이 지정한 도움말로 교체했습니다.

빨간 선에 닿기 전에 내려오는 숫자 블록을 하단의 버튼을 눌러 제거하세요.
키보드 1~4 또는 A/S/D/F로도 버튼을 누를 수 있습니다. B는 버스트, P 또는 Esc는 일시정지입니다.

한국어 문구를 그대로 반영하고 줄바꿈을 유지했습니다. 영어 도움말도 같은 내용으로 맞췄습니다. 버스트의 상세 규칙 설명은 도움말 본문에서 제거했으며 게임 동작은 변경하지 않았습니다.

빌드·빌드 분리·문법·변경 공백 검사와 빌드 결과의 문구 일치를 확인했습니다. 로컬 랩은 새로고침하면 반영됩니다.
