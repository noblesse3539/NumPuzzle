# [0006 | 2026-09-08] 추가 05회차 — 위기와 성취 알림의 우선순위

상태: 구현 완료 · 실행 검증 전

## 문제와 판단

클러치·최고기록·버스트·번개가 같은 시점에 발생하면 마지막 텍스트만 보이기 쉽습니다. 제안서 8·9쪽의 결정적 성취를 읽을 수 있도록 중요도를 구분합니다.

## 구현한 내용

- 알림에 우선순위를 부여했습니다. 버스트 완성, 클러치·기록, 버스트 시작, 준비, 종료, 번개 순으로 중요도를 둡니다.
- 덜 중요한 알림은 최대 3개까지 잠깐 보류하며 4초가 지난 이벤트는 버립니다. 준비·발동 상태가 이미 끝난 알림도 버립니다.
- 위험 라인에 느낌표를 표시해 색상 외 구분을 추가했습니다. 실제 클러치 성공에는 레드라인 주변에 0.7초 동안 초록색 해소 표시를 줍니다.

## 정적 검토 기록

보류 큐의 중복 제거와 최대 길이를 정적으로 검토했습니다. 클러치 효과는 기존 실제 위험 해소 판정을 통과한 경우에만 시작합니다.

창작자님 요청에 따라 실제 플레이, 브라우저/자동화 테스트, 빌드 실행과 배포는 수행하지 않았습니다. 이 기록은 동작 성공이나 몰입도 향상을 검증했다는 의미가 아닙니다.

## 통합 정리

통합 정적 검토에서 버스트 완성과 같은 입력에 발생한 최고기록·클러치도 우선순위 큐로 전달하도록 보완했습니다.

## 남은 과제

여러 이벤트가 겹치는 실제 화면에서 중요 정보가 남는지 확인해야 합니다. 이미 높은 우선순위로 바뀐 낮은 알림을 모두 다시 보여주지는 않습니다.
