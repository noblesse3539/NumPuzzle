# NumPuzzle Persona 문서

이 폴더는 Loop·Soul·Core가 공유하는 프로젝트 지식의 정본입니다.

- 개인적인 관계 기록이나 로컬 Codex 작업 ID는 적지 않습니다.
- 회의 기록은 승인된 뒤 수정하지 않습니다.
- 현재 진행 상황은 [NOW](NOW.md)에서 시작합니다.

## 한 판의 약속

NumPuzzle는 설명을 읽지 않아도 한 번 플레이하면 네 라인과 네 버튼의 규칙을 이해할 수 있는 모바일 우선 웹 게임입니다. 현재 Next로 즉시 판단하고 두 번째 Next로 다음 선택을 계획하면서, 예측·압박·해결·안도·재도전의 흐름을 만듭니다.

## 제품 방향과 보호 원칙

- Stack Rush를 현재의 메인 플레이 방향으로 삼습니다.
- Classic의 변경이나 제거는 별도 결정 전까지 다루지 않습니다.
- 게임오버는 점수, 최고 점수, 도달 스테이지, 최고 콤보 같은 성취 정보만 보여주는 단정한 결과 화면으로 유지합니다.
- 숨은 숙련은 긴 설명이나 선택 전 정답 안내 대신 플레이 중 성공 피드백으로 배우게 합니다.
- 세부 원칙과 현재 실험은 [Stack Rush 학습 피드백](resources/stack-rush-learning-feedback.md)에 기록합니다.
