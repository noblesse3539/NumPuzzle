# [0007 | 2026-09-08] 추가 06회차 — 선택 가능한 효과음과 진동

상태: 구현 완료 · 실행 검증 전

## 문제와 판단

제안서 3쪽의 시각·소리·손끝 반응 중 이전 구현에 없던 소리와 진동을 추가합니다. 각각 끌 수 있어야 하며 브라우저 지원 여부가 게임을 막아서는 안 됩니다.

## 구현한 내용

- 숫자 1~4에 짧은 서로 다른 정답 음을 대응시키고, 오답·버스트 시작·완성 효과음을 추가했습니다. 외부 음원 대신 짧은 합성음을 사용합니다.
- BGM과 독립된 효과음 설정을 추가했습니다. 효과음은 기본 켜짐, 진동은 기본 꺼짐입니다.
- 사용자가 진동을 켜면 짧은 정답 반응과 버스트 완성 패턴을 요청합니다. 지원하지 않는 기기에서는 조용히 생략합니다.
- 동시 음성 수를 12개로 제한하고 종료·일시정지·새 판·메뉴 이동 시 정리합니다. 로컬 설정 안내를 개인정보처리방침에도 반영했습니다.

## 정적 검토 기록

오디오 생성·재생과 진동을 예외 보호로 감쌌습니다. 사용자 입력에서만 오디오 활성화를 시도하고 게임 진행은 오디오 준비를 기다리지 않습니다. BGM의 AudioContext와 별개이므로 BGM 음소거가 효과음 상태를 바꾸지 않습니다.

창작자님 요청에 따라 실제 플레이, 브라우저/자동화 테스트, 빌드 실행과 배포는 수행하지 않았습니다. 이 기록은 동작 성공이나 몰입도 향상을 검증했다는 의미가 아닙니다.

## 남은 과제

모든 소리의 실제 청취·음량 평가와 iOS/Android 진동·오디오 재개는 검증 전입니다. 음악 버튼은 BGM 전용이며 전체 무음은 설정에서 효과음도 꺼야 합니다.
