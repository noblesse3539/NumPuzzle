# FOURCAST 후속 5회 개선·통합 검증·직접 플레이

작성일: 2026-09-09

## 완료 결과

[이전 보고서의 추천](통합_검증과_20스테이지_플레이.md)을 바탕으로 **구현과 기록 5회 → 일괄 통합 테스트 → 실제 버튼으로 20스테이지 클리어** 순서로 진행했습니다. 회차별 구현 중에는 실행 검사를 하지 않았습니다.

직접 플레이 결과는 **31,881점·679콤보, 20스테이지 54/54 제거 후 21스테이지 진입**입니다. 라인 버튼 679회, 버스트 버튼 9회 입력했고 의도적으로 오답을 내는 막힘 대응은 필요하지 않았습니다. 게임은 21스테이지 시작에서 일시정지했습니다.

블록 그림은 논리 높이와 일치해야 하므로 화면에 따라 직사각형이 됩니다. 3% 간격은 유지합니다. 10% 보드 높이를 기준으로 정규화한 위치는 화면 변경 때 그대로 유지합니다.

버스트 연결은 충전된 버튼을 직접 누를 때만 발생합니다. 무료 블록 제거·무료 점수·자동 숫자 교체는 없습니다. 현재 정답이 있으면 공개된 두 숫자를 유지합니다. 버스트의 충전 16개, 6초, 낙하 40%, 네 번 성공 +100점과 기존 콤보 점수 공식도 유지했습니다.

신규 검사의 근거:

- 고정 시드의 보드 512개에서 후반 NEXT 12,800개를 생성해 최소 한 정답 경로가 존재하는지 검사했습니다.
- 초반/버스트 후보 1,536개에서 모든 현재 정답 선택 뒤의 연결을 검사했습니다.
- 320×568, 390×844, 430×932, 1280×900과 다시 돌아온 390×844에서 1~50스테이지 프로필이 모두 동일했습니다. 모든 화면에서 20스테이지 목표는 54개였습니다.
- 크기 변경 전후의 블록 논리 위치가 같고 실제 높이 비율은 약 10%였습니다. 작은 화면 이미지를 직접 확인했습니다.
- 급한 5회 입력이 즉시 한 발·예약 한 발로 끝나며, NEXT가 바뀐 예약은 폐기됐습니다.
- 막힌 버스트 연결만으로 점수나 블록 수가 바뀌지 않았고, 이후 실제 네 번 성공 결과는 기존 규칙대로 143점이었습니다.
- 정상 NEXT 보존, 충전 전 연결 금지, 번개 재표시 제한, 종료된 버스트의 오래된 연결 알림 폐기를 확인했습니다.

이번 통합 검사에서는 추가 제품 결함이 발견되지 않아 회차 완료 뒤 별도의 제품 수정은 필요하지 않았습니다. 검사 기준을 낮추거나 실패 항목을 제외하지 않았습니다.

테스트의 상태 설정 장치는 테스트 브라우저에만 삽입합니다. 직접 플레이용 production 파일과 배포 산출물에는 포함하지 않습니다. 실제 iPhone/Android 기기, 음질·진동 체감·발열·프레임 성능은 아직 검증하지 않았습니다.

## 직접 플레이에서 확인한 내용

보이는 NEXT·미리보기·라인 숫자와 위치를 읽어 실제 UI 버튼을 눌렀습니다. 다음 미리보기가 남는 선택을 우선하고, 이어지는 후보 중 아래쪽 라인을 골랐습니다. 상태 주입·단계 이동·속도 변경·점수 편집을 사용하지 않았습니다. 각 기록 시점의 화면은 547×1072로 유지됐습니다.

버스트는 위기 또는 선택 가능한 후보가 보이지 않을 때 사용하도록 관찰했습니다. 결과를 정리하니 **9회 중 5회는 ‘막힌 NEXT 연결’, 4회는 일반 발동**이었습니다. 일반 발동도 위험선 근접이라고 확정할 근거가 없으므로 ‘위험선에서 9회 구조’로 해석하면 안 됩니다. 중간 설명에서 첫 발동을 위험선 접근으로 설명했으나 실제 기록은 NEXT 막힘이었으며 여기서 바로잡습니다.

9회의 성공 알림을 관찰했고 679콤보가 유지됐습니다. 따라서 이번 판에서는 오답 비용으로 흐름을 되살릴 필요가 없었습니다. 다만 정답 경로 보장은 **이어갈 실제 블록이 있을 때의 보장**입니다. 보드를 빠르게 비우고 예정 공급을 기다리는 구간까지 없앤 것은 아닙니다.

이전 빌드와는 목표·보드 비율이 달라 점수 상승만으로 재미나 난도 개선을 증명하지 않습니다. 도구로 정확히 입력한 판은 사람의 반응 속도·학습·손가락 피로를 대신하지 못합니다.
