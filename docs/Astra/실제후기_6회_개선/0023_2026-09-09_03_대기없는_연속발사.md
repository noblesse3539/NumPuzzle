# [0023 | 2026-09-09] 애니메이션을 기다리지 않는 연속 발사

작성일: 2026-09-09

## 실제 후기 대응

기존에는 127ms 비행과 160ms 제거가 끝나야 다음 발사를 처리했습니다. 앞서 만든 예약 하나 제한도 이 대기를 없애지는 못했습니다. 이번 후기의 빠른 연속 발사를 위해 그 정책을 교체합니다.

입력 이벤트마다 현재 NEXT에 대해 판정·블록 처리·점수·다음 NEXT 갱신을 즉시 수행합니다. 한 이벤트의 변경을 화면에 반영한 뒤 다음 이벤트를 받습니다. 입력 대기열은 사용하지 않습니다. 오답도 즉시 페널티 블록과 콤보 손실로 처리됩니다. 누르고 있는 키의 자동 반복 제외는 유지합니다.

비행은 70ms, 적중 잔상은 뒤이어 100ms 동안 별도 장식으로 표시합니다. 최대 12개로 제한하고 정지 시 진행하지 않으며 스테이지·메뉴·종료에서 제거합니다. 장식은 정답 후보나 충돌에 포함하지 않습니다. 퍼펙트·버스트 보상은 기존 판정 함수를 사용합니다.

연속 발사에는 인위적인 속도 제한이 없지만 기기 렌더링 성능과 실제 사람이 읽는 속도까지 보장하지는 않습니다. 동시·빠른 입력, 오답, 전환 경계는 마지막 통합 검증에 포함합니다.
