# [0026 | 2026-09-09] 작업 기록의 순서 규칙

작성일: 2026-09-09

모든 Markdown 기록의 파일명은 `NNNN_YYYY-MM-DD_작업명.md`, 첫 제목은 `[NNNN | YYYY-MM-DD] 작업명`으로 통일합니다. NNNN은 회차 그룹과 관계없이 작성 순서로 증가합니다. 기존 회차 번호는 작업명에 남길 수 있습니다. 날짜가 같아도 번호로 순서를 알 수 있습니다.

기존 최초 개선→10회 개선→검증→5회 개선→Git 전달→이번 실제 후기 대응 순서로 기존 기록의 제목과 파일명을 변경합니다. 원래 내용과 사용자가 수정한 본문은 보존하고 상대 링크를 함께 갱신합니다. JSON 검증 증거의 이름은 그대로 유지합니다. `0000_작업기록_목차.md`가 시간순 진입점입니다. 이후 새 문서는 목차의 마지막 번호 다음을 씁니다.

전체 구현 완료 뒤 통합 검증 결과를 총괄 문서에 추가합니다.

최종 상태: 전체 구현 후 통합 검증 완료. [검증 결과와 다음 과제](../0027_2026-09-09_실제후기_6회_개선_총괄.md)를 참고하세요.
