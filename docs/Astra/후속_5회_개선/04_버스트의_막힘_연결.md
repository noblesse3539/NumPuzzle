# 04회차 — 버스트를 아껴 쓸 이유

작성일: 2026-09-09

## 문제와 결정

이전 판에서는 버스트를 충전 즉시 쓰는 전략이 많았고, 막힌 순간에는 버스트 시간이 보호돼도 보드가 계속 내려와 실패했습니다. 준비된 버스트에 명확한 위기 대응 기능을 부여합니다.

## 구현

현재 NEXT와 맞는 맨 아래 블록이 없을 때 준비된 버스트를 직접 누르면, 현재 NEXT를 가장 아래에 있는 선택 가능한 블록의 숫자로 연결합니다. 다음 미리보기는 버스트의 안전 후보 규칙으로 생성합니다. 바뀐 NEXT는 즉시 화면에 반영하고 기존 알림 자리에 ‘막힌 NEXT 연결’을 표시합니다.

현재 정답이 존재하면 공개한 두 숫자를 그대로 유지합니다. 비어 있는 보드에 새 블록을 생성하지 않습니다. 연결 자체는 점수를 주거나 블록을 지우지 않고, 퍼펙트 예약만 해제합니다. 이후 실제 4연속 정답을 해야 +100점을 받습니다. 16개 충전·6초·40% 속도·성공 뒤 1.2초 해소는 유지합니다.

준비 버튼과 도움말에 이 용도를 알립니다. 내부 연결 횟수도 세어 최종 검증에 활용합니다. 계정·외부 수집은 추가하지 않았습니다.

## 회차 종료 상태

구현·기록 완료. 테스트는 5회차 후 진행합니다. 막힘 연결, 정상 NEXT 유지, 준비 전·정지 중 발동 금지, 연결 후 실제 4연속 성공, 중복 보너스 방지를 확인할 예정입니다.
