# Stack Rush를 메인으로 하고 깊이는 플레이 중 성공 피드백으로 가르친다

Stack Rush를 앞으로의 메인 플레이 방향으로 삼는다. Classic 제거는 별도 회의에서 다루며 이번 결정과 구현 범위에서는 Classic을 변경하지 않는다. 게임오버 화면은 성취 정보만 유지한다. 안전 체크 해제 이후의 두 Next 읽기는 선택 전 안내 대신 성공 이후의 짧은 연출로 학습시키며, 정확한 수치와 연출 강도는 실험으로 남긴다.
