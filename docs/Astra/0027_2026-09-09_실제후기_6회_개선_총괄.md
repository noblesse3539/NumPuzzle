# [0027 | 2026-09-09] 실제 후기 대응 6회 개선과 검증

작성일: 2026-09-09

## 기준과 구현

실제 플레이에서 나온 ‘난도 템포가 느리고 한 판이 길다’, ‘연속 발사의 대기가 답답하다’를 최우선으로 삼았습니다. 이번에는 PDF를 다시 참고하지 않았습니다. 6회 구현을 모두 마친 뒤 통합 테스트를 진행하고, 발견한 실험실 초기화 문제를 수정한 뒤 관련 검사를 다시 통과했습니다.

1. 일시정지 글자를 도형으로 바꿔 중앙 정렬을 바로잡았습니다.
2. 최대 90초 라운드, 12초 단계, 빠른 낙하 곡선과 짧은 전환을 적용했습니다.
3. 발사 판정·NEXT 갱신과 비행 연출을 분리해 입력 대기를 제거했습니다.
4. 빈 보드 공급 대기를 줄이고 짧은 대기 안내를 숨깁니다.
5. 새 규칙 최고점·직전 판과 이전 기록을 분리 보존합니다.
6. 과거 기록까지 순서·날짜가 드러나는 제목으로 바꾸고 목차와 링크를 갱신했습니다.

연속 버튼 클릭 8회를 약 24.6ms 안에 처리해 정답 8개·콤보 8개·대기 입력 0개를 확인했습니다. 이는 데스크톱의 프로그램 입력 검사이며 사람의 손가락 반응 시간이나 휴대폰 성능 수치가 아닙니다. 오답 직후 정답, 중복 보상 방지, 스테이지를 끝내는 연타, 장식 12개 제한도 확인했습니다.

90초 종료는 버스트 감속, 늦어진 프레임, 스테이지 휴식에서도 지켜졌고 수동 정지는 제외되었습니다. 실험실 시나리오 준비에 제한시간 초기화가 빠진 것을 보완했습니다. 보완 중 잘못 참조한 초기화 함수는 재검사에서 발견해 실제 상태 생성 함수로 수정했고, 최종 실험실 검사는 모두 통과했습니다.

320×568, 390×844, 547×880, 1280×900에서 일시정지 막대와 계속하기 버튼의 가로 중심이 일치했습니다. 문구 중심 오차는 글자 배치의 소수점 반올림에 해당하는 0.008px 이하였습니다. [390px 화면](실제후기_6회_검증/pause-390.png)도 눈으로 확인했습니다.

이전 최고점 31,881점과 예전 직전 판을 유지한 채 새 규칙 최고점 10점과 규칙 ID가 있는 새 직전 판을 별도로 저장하는 검사도 통과했습니다.

## 직접 화면을 조작한 결과

새 production 페이지에서 보이는 NEXT와 각 라인의 가장 아래 블록을 읽고 실제 버튼을 눌렀습니다. 점수나 게임 상태를 주입하지 않았습니다. 시작 버튼 후 약 45초 시점에 148회 정답, 2,649점, 8스테이지, 남은 시간 48초를 확인했습니다. 준비 시간을 제외하면 약 42초 진행입니다. 이어지는 도구 호출 사이에 입력이 멈춰 이후 위험선으로 종료되었으며, 약 58초 시점에 같은 점수와 148콤보의 결과 화면을 확인했습니다.

이 관찰은 빠른 입력과 단계 전개의 연결을 확인한 결과입니다. 도구 호출 공백이 있으므로 평균 생존 시간이나 숙련자 난도의 근거로 쓰지 않습니다. 이번 작업에서 20스테이지 완주를 새로 달성한 것은 아닙니다. 기존 20스테이지 기록은 이전 규칙의 역사입니다. [관찰 수치](실제후기_6회_검증/ui-play-result.json)를 함께 남겼습니다.

## 다음 방향과 과제

방향은 **짧은 한 판 안에서 바로 반응하고 다시 도전하는 네 버튼 게임**입니다. 설명이나 패널을 늘리기보다 실제 손의 속도와 보드 읽기를 다듬습니다.

1. **실제 휴대폰 재평가가 우선입니다.** 기존 후기 제공자에게 새 버전을 각각 3판 이상 플레이하게 하고, 종료까지 걸린 시간·첫 실수 시점·답답한 대기 여부·즉시 재도전 의향을 확인합니다. iOS Safari와 Android Chrome에서 두 손가락 연타, 음향과 진동, 저사양 발열도 따로 봅니다.
2. **90초와 첫 낙하 12초는 검증할 초안입니다.** 시작부터 너무 가혹한지, 반대로 숙련자에게 아직 긴지 구분합니다. 무조작 판은 빠르게 끝납니다. 첫 실패가 지나치게 빠르면 전체 판을 늘리기보다 초반 몇 초의 여유를 조정합니다. 더 짧은 60초안은 피드백이 모인 다음 비교합니다.
3. **읽기 속도와 연타 안전성을 확인합니다.** 즉시 NEXT가 바뀌므로 잘못된 두 번째 탭도 즉시 처리됩니다. 실제 오입력률이 높다면 인위적인 발사 지연을 되돌리기 전에 버튼 피드백과 여러 손가락의 입력 순서를 점검합니다.
4. **공급 공백과 선택 분기를 나눠 봅니다.** 이번 로컬 대기 진단으로 빈 보드, 예정 공급, 분기 막힘을 구분할 수 있습니다. 빠른 플레이에서 어떤 공백이 많이 생기는지 먼저 측정하고, 막힘 해결이 필요하면 기존 버스트 연결을 중심으로 조정합니다.
5. **장기 기록보다 동일 규칙 안의 재도전을 개선합니다.** 새 규칙의 완주율과 점수 분포를 확인한 뒤 목표 문구를 다듬습니다. 점수·콤보 공식의 재조정은 별도 판단 대상으로 남겼습니다. Classic 동작은 이번 변경 대상이 아니며 새 모드를 늘리지 않았습니다.
