# 개발 전용 Stack Rush Lab과 프로덕션 산출물을 분리한다

Stack Rush의 고스테이지와 두 번째 Next 학습 피드백을 반복 검증하기 위해 개발 전용 Lab을 별도 진입점으로 만든다. Lab은 허용 목록형 시나리오와 제한된 조작만 제공하며 실제 게임의 입력·판정·전환 경로를 사용한다. 프로덕션 산출물에는 Lab 화면, 조작기, 디버그 API와 식별자가 포함되지 않도록 별도 빌드와 산출물 검증을 둔다. 배포 대상은 프로덕션 산출물로 고정한다. 이 결정은 Classic, 실제 모바일 플레이 화면, 게임오버 결과 화면을 변경하도록 승인하지 않는다.
