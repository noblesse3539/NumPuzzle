# [0015 | 2026-09-09] 02회차 — 화면 크기와 난도 분리

작성일: 2026-09-09

## 문제와 결정

이전 플레이에서 같은 16스테이지 목표가 43개와 23개로 달랐습니다. 정사각 블록의 픽셀 높이/보드 높이가 공급 간격 계산에 들어가고, 초기 화면 측정 후 목표를 다시 계산하던 구조였습니다.

## 구현

논리 블록 높이를 보드 높이의 10%, 웨이브 간격을 블록 높이의 3%로 통일했습니다. 실제 블록 그림의 높이도 같은 비율을 쓰므로 충돌과 표시가 일치합니다. 가로 폭은 기존 범위를 유지해 화면에 따라 직사각형이 될 수 있으며 숫자 크기는 가로·세로 중 작은 쪽을 따릅니다.

시작·화면 변경 때 측정은 표시 크기만 바꿉니다. 블록의 정규화 위치, 위험선 거리, 스테이지 목표·낙하 시간·공급 예산은 바뀌지 않습니다. 숨겨진 화면의 0 크기도 저장하지 않습니다. 초기 웨이브 측정에서 목표를 재계산하던 코드를 제거했습니다.

낙하 시간 계수와 점수 공식은 유지합니다. 이 변경 전후 기록은 논리 보드 조건이 달라 동일 난도 기록으로 비교하면 안 됩니다. 기존 개인 최고점은 삭제하지 않습니다.

## 회차 종료 상태

소스·화면 스타일·기록 작성 완료. 실행 검증은 5회차 뒤에 진행합니다. 여러 화면에서 1~30스테이지 프로필 동일성, 플레이 중 크기 변경, 3% 간격·충돌, 숫자 가독성을 확인할 예정입니다.
