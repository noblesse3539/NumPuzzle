# 03회차 — 보이는 NEXT에 묶인 연속 입력

작성일: 2026-09-09

## 문제와 결정

이전 직접 플레이의 빠른 입력은 애니메이션 중 네 번까지 쌓일 수 있었습니다. 그 입력이 아직 표시하지 않은 숫자에 차례대로 소비되면 플레이어 의도와 다른 오답이 발생할 수 있습니다.

## 구현

처리 중에는 현재 화면에 공개한 NEXT에 대한 입력 하나만 저장합니다. 저장한 입력은 NEXT의 세대 번호와 숫자에 묶고, 처리 직전에 일치 여부를 확인합니다. 대기 입력이 이미 있으면 추가 클릭을 저장하지 않고 버튼에 대기 표시를 남깁니다. 다음 숫자를 미리 읽고 두 번째 정답을 예약하는 조작은 유지합니다.

키보드 반복 제외, 정지·스테이지 전환·새 판에서 대기 입력 제거는 유지합니다. 잘못 고른 라인을 정답으로 바꾸는 보정은 하지 않습니다. 잘못된 라인 번호도 진입점에서 거릅니다.

## 회차 종료 상태

구현·기록 완료, 실행 검증은 아직 하지 않았습니다. 최종 검사에서 빠른 5회 입력이 최대 두 발로 끝나는지, 저장 중 NEXT 교체 시 폐기되는지, 퍼펙트 연속 입력과 정지 경계를 확인합니다.
