# [0005 | 2026-09-08] 추가 04회차 — 빠른 정답의 번개 연쇄

상태: 구현 완료 · 실행 검증 전

## 문제와 판단

제안서 7쪽은 빠르게 이어 낸 판단의 궤적을 눈에 보이게 만들 것을 제안했습니다. 점수 경쟁 요소를 늘리기보다 이미 잘한 플레이를 보여주는 효과로 구현합니다.

## 구현한 내용

- 정답 제거 사이 간격이 각각 0.8초 이내인 네 번의 성공을 번개 연쇄로 기록합니다.
- 실제 맞힌 라인의 위치들을 짧은 선으로 연결합니다. 한 번에 하나의 궤적만 만들며 550ms 뒤 제거합니다.
- 오답·스테이지 보드 교체·새 판에는 연속 기록을 초기화합니다. 추가 점수는 없고 성공 횟수는 상태에서 관찰할 수 있습니다.
- 모션 감소 설정에서는 선을 만들지 않고 텍스트 피드백만 남깁니다.

## 정적 검토 기록

화면 크기에 대한 백분율 좌표를 사용하고 SVG는 `pointer-events: none`으로 처리했습니다. 실패 입력은 기록에 들어가지 않으며 생성한 DOM은 정리 경로를 갖습니다.

창작자님 요청에 따라 실제 플레이, 브라우저/자동화 테스트, 빌드 실행과 배포는 수행하지 않았습니다. 이 기록은 동작 성공이나 몰입도 향상을 검증했다는 의미가 아닙니다.

## 남은 과제

입력 처리 지연까지 포함한 0.8초 기준이 적절한지, 같은 라인을 연속 선택했을 때 궤적이 충분히 보이는지 실제 검증이 필요합니다.
