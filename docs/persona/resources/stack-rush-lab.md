# Stack Rush 개발 Lab

## 목적

고스테이지와 완벽 판정·점수, Stage 11 preview 맥동을 실제 플레이로 Stage 10까지 반복 진행하지 않고 재현합니다. Lab은 넓은 데스크톱 전용 웹 화면이며, 실제 모바일 게임 프레임을 왼쪽에 그대로 두고 개발 조작을 오른쪽 바깥 패널에 둡니다.

## 재현 원칙

Lab의 시나리오 지휘자는 필요한 스테이지·보드·큐·난수·시간 같은 사전조건만 준비합니다. 맥동이나 잔광 애니메이션을 직접 호출하지 않으며, 이후 실제 라인 입력·적중 판정·스테이지 전환·레드라인 경로가 연출과 결과를 발생시킵니다.

임의 함수 실행 콘솔과 임의 상태 편집은 제공하지 않습니다. 스테이지 선택은 정수 범위로 제한하고, 시나리오와 실행 동작은 이름 있는 허용 목록으로 관리합니다.

완벽은 현재 Next와 일치하는 실제 라인 중 다음 가시 블록이 preview와 같고, 해당 라인을 제거한 뒤 preview를 놓을 실제 라인이 정확히 하나일 때만 활성화됩니다. 첫 라인을 맞힌 뒤 같은 라인의 승격 preview를 이어서 맞히면 성공 점수에 50점을 더합니다. 기본 점수는 콤보 1에서 10점, 콤보 2~10에서 11점, 콤보 11~20에서 12점이며 이후 10콤보마다 1점씩 증가합니다.

## 첫 시나리오

- Stage 10의 마지막 실제 적중으로 Stage 11에 진입해 preview 토큰의 300ms 맥동 3회를 확인합니다.
- 현재 선택지가 여러 개여도 preview까지 이어지는 실제 경로가 하나일 때만 두 번 연속 입력으로 완벽과 50점 보너스를 재현하고, preview를 놓을 라인이 여러 개인 무효 경로도 비교합니다.
- 실제 레드라인 경계 판정 뒤 게임오버 화면 대신 같은 Lab 시나리오를 자동 초기화합니다.

## 웨이브 간격 검증

- 05번 케이스는 라인 끝에 주차된 두 패널티를 신규 웨이브 아래로 먼저 합류시키고, 고정 `2px` 대신 실제 블록 높이의 `3%` 외곽 간격과 기존 하위 블록의 순차 리플로우·최대 겹침을 확인합니다.
- 06번 케이스는 웨이브 진입 전후 240ms를 프레임 단위로 수집해 중심·외곽 간격, 간격 흔들림, 이동 속도 편차, 새 타일 외곽 크기의 `0.28 → 1` 확대와 정착을 표시합니다.
- 모바일 주소창·회전으로 게임 프레임 높이가 바뀌어도 기존 블록 중심을 보존한 뒤 새 블록 크기로 비율을 다시 계산합니다.

## 배포 경계

프로덕션과 Lab은 별도 진입점과 별도 산출물로 만듭니다. 실제 배포 대상은 프로덕션 산출물 하나뿐입니다. 프로덕션에는 Lab 화면, 메시지 브리지, 시나리오 지휘자, 시나리오 식별자와 개발 전용 API가 없어야 하며, 빌드 검증이 이를 발견하면 실패합니다.

Classic, 실제 모바일 플레이 화면과 게임오버 결과 화면은 Lab 도입으로 변경하지 않습니다.
